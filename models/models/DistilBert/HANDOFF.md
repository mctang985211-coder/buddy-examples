## Artifacts

Directory: `bb-tests/workloads/src/ModelTest/e2e/models/models/DistilBert/`

| File | Role |

Traces `DistilBertForMaskedLM` with `DynamoCompiler(primary_registry=tosa.ops_registry, aot_autograd_decomposition=inductor_decomp)`, fuses with `simply_fuse`, writes `forward.mlir`, `subgraph0.mlir`, `arg0.data`, `arg1.data`, then re-reads the parameter blobs and requires a bit-exact round trip. The `@forward` signature `distilbert-main.cpp` is written against — read from the emitted
`output/forward.mlir`, not assumed:

```mlir
func.func @forward(%arg0: memref<66985530xf32>, %arg1: memref<512xi64>,
                   %arg2: memref<1x11xi64>, %arg3: memref<1x11xi64>) -> memref<1x11x30522xf32>
```

DistilBERT takes **no** `token_type_ids`, so the driver passes one runtime argument fewer than
`Bert/bert-main.cpp`; the classifier's 6-wide output is replaced by the 30522-wide masked-LM logits.

## Canonical Reference

Produced with the **official implementation** (upstream `transformers 5.5.4`,
`torch 2.12.0`, CPU), never with a hand-written reimplementation, and never reduced to an argmax:

```
python3 pytorch-distilbert-mlm.py --write-reference
-> wrote .../reference/distilbert_mlm_logits_f32.bin (1342968 bytes, sha256 8830763a4fdb2d6f...)
-> reference logits shape=(1, 11, 30522) cpu_inference=0.034s
```

* Fixed input (from `reference_manifest.json`): `"The quick brown fox jumps over the lazy dog"`
  → `input_ids = [101, 1996, 4248, 2829, 4419, 14523, 2058, 1996, 13971, 3899, 102]`,
  `attention_mask = [1] * 11`. The sentence deliberately contains no `[MASK]`/`[SEP]` substring so
  that upstream WordPiece and buddy's C++ `tokenizeBert` agree on the ids.
* Canonical tensor: `distilbert_mlm_logits_f32.bin`, shape `[1, 11, 30522]`, float32,
  `sha256 8830763a4fdb2d6f782353949c9baaf906a1a9b15a405774719c4c4da0f2a7b6`.
* **Reproducibility:** a second run into a different directory
  (`--reference-dir /home/ROXY/code/bb_work/buckyball/.dsh/ref2`) produced byte-identical output —
  both files hash to the sha256 above.
* **Agreed tolerance:** `np.allclose(atol=1e-3, rtol=1e-3)` on the *complete* logits tensor
  (335,742 elements), plus exact `argmax` and exact top-5 token-id agreement, plus
  `relative_l2_error` reported for transparency. `atol/rtol=1e-3` is the same bar used by the
  upstream buddy-mlir JIT check (`compiler/thirdparty/buddy-mlir/examples/BuddyJIT/
  pytorch_matrix_multiplication.py`), and is required here because float32 reassociation moves a
  few near-zero logits by up to 2e-4 (see **Known Limitation** #5).

## Local Run

**Device: host CPU** (x86-64). GPU was not needed and is not available here:
`torch.cuda.is_available()` → `False`, and the canonical single inference takes 0.034 s, far
below the 10 s threshold in the playbook.

Environment (nix env of the buckyball repo; `result/bin/python3` = Python 3.14.6 with
`torch 2.12.0`, `transformers 5.5.4`):

```bash

export BB=$PWD
export RISCV=$BB/result
export BUDDY_MLIR_BUILD_DIR=$BB/compiler/thirdparty/buddy-mlir/build
export LLVM_MLIR_BUILD_DIR=$BB/compiler/thirdparty/buddy-mlir/llvm/build

cd bb-tests/workloads/src/ModelTest/e2e/models/models/DistilBert
# 1) canonical reference (official implementation)
python3 pytorch-distilbert-mlm.py --write-reference
# 2) local run: AOT import + execute the imported graph on the host CPU
python3 import-distilbert.py --output-dir output --jit-check \
        --dump-candidate output/jit_logits_f32.bin
# 3) independent re-check of the dumped output through the workload's own checker
python3 pytorch-distilbert-mlm.py --check output/jit_logits_f32.bin
```

## Known Limitation

1. **`distilbert-main.cpp` is not compiled or run in this stage.** Linking it needs the chip-bound
   `buddy-opt`/`buddy-translate`/`buddy-llc` pipeline, explicitly out of scope here. It is checked
   two ways instead: its `extern "C"` declaration matches the `@forward` signature read from the
   emitted `output/forward.mlir`, and `g++ -fsyntax-only -Wall` passes against the buddy headers
   (see **Build Binding**).
2. **`workload --build --chip toy` cannot select this model yet.** By design this stage adds no
   `archs/buckyball/<chip>/DistilBert/` layout and no `MODEL_LAYOUT` / `build.py::_MODELS` entry,
   so `chips_for_model()` returns an empty set and the step would abort with
   `unsupported_chip_model`. The expected `bebop-bemu --batch '--chip toy --test elf-tests'`
   therefore belongs to the next stage; the model-side CMake target is verified through the
   configure/build commands in **Build Binding**.
3. **C++ tokenizer parity is asserted, not executed.** `Text::tokenizeBert` agrees with upstream
   WordPiece for the chosen sentence only because it contains no special-token substrings; that
   claim cannot be verified until the driver is linked (limitation #1).
4. **Parameter packing follows the Bert convention by assumption**: every parameter but the last is
   float32 and the last one is the int64 buffer. Verified for this checkpoint
   (`len(params) == 106`, `params[105].dtype == int64`, shape `(1, 512)`;
   66,985,530 float32 elements = the Hub's F32 parameter count) and enforced at build time by the
   bit-exact read-back in `verify_param_files()`. A future checkpoint with several int64 buffers
   would need the importer changed.
5. **`max_rel_diff` is 1.58 while `mean_abs_diff` is 2.35e-5.** The relative figure comes from a
   handful of logits whose reference value is ~1e-4, where float32 reassociation dominates; this is
   why the agreed metric is `np.allclose(atol=1e-3, rtol=1e-3)` on the whole tensor plus relative-L2
   (5.62e-6) plus exact top-5 id agreement, rather than a pure relative bound. The 10 s threshold in
   the playbook applies to the model run (0.034 s on CPU), not to the one-off 49.2 s JIT compile.
6. **Environment notes (not workload defects).** `huggingface.co` is unreachable from this machine,
   so the checkpoint was fetched through the HF mirror (`HF_ENDPOINT=https://hf-mirror.com`) into
   `.dsh/hf-cache` (git-ignored) and every run used `HF_HUB_OFFLINE=1`; reviewers need the same
   `distilbert/distilbert-base-uncased` files (5 files, 257 MB) in their `HF_HOME`. The harness
   tools contributed by the `workload-integration` plugin are unusable in this session because the
   plugin's `repoPath` config is empty — `buckyball_existing_models_index` and
   `buckyball_workload_audit` both abort with `The "paths[0]" argument must be of type string.
   Received undefined`, and `buckyball_model_info` with `fetch failed`. The audit was therefore run
   by importing the plugin's own `src/tools/workload-audit.ts` verbatim (only its `defineTool`
   import redirected to an identity stub) with `repoPath=/home/ROXY/code/bb_work/buckyball`:
   `node --experimental-strip-types .dsh/run-workload-audit.mjs DistilBert
   workloads/src/ModelTest/e2e/models/models/DistilBert/reference/distilbert_mlm_logits_f32.bin`.
   Fixing the plugin config (`repoPath` in the profile) is the real remedy.
7. **A 1.34 MB binary reference file is committed.** It is the full canonical logits tensor, which
   the "compare the complete output, not just an argmax" rule calls for; it is regenerable and
   pinned by the sha256 in `reference/reference_manifest.json`. It lives in the `e2e` submodule,
   which has no `check-added-large-files` hook installed (the parent repo's pre-commit only sees
   its own tracked files, so the gitlink bump is unaffected).
8. **`__pycache__/` and `output/`** are produced by running the scripts; both are ignored
   (`e2e/.gitignore`, `models/models/.gitignore`, this directory's `.gitignore`).
